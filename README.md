# rc_drift_car
This is a project of a radio-controlled drift car. We offer two options for assembling Arduino (remote control) - Arduino (receiver). Or Arduino (remote control) - Raspberry (receiver).

1) receiver_arduino.сpp The first code is the code for the machine itself, which contains the Arduino.
2) receiver_raspberry.py The second code is the code for the machine itself, in which the Raspberry is located.
3) transmitter_arduino.cpp The third code is the code for the transmitter (remote control) in which there is an arduino.
